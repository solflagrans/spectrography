# Интерпретатор спектра

Локальное Next.js-приложение для проверяемой интерпретации спектральных измерений: импорт данных, подготовка сигнала, поиск пиков, сопоставление с атомными линиями и анализ молекулярных полос N₂/N₂⁺.

## Запуск

Требуются Node.js 20.9+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Полная проверка проекта:

```bash
pnpm check
```

Архитектура и предметные решения описаны в [AGENTS.md](./AGENTS.md), аналитический конвейер — в [docs/analysis-pipeline.md](./docs/analysis-pipeline.md), контроль производительности — в [docs/performance.md](./docs/performance.md).
