# Открытый экспериментальный спектр

`zenodo-14843545-fig2-total-300-400nm.tsv` — явно обозначенная производная выборка из экспериментального файла `Fig_2_total.dat` набора Zenodo 14843545. Это не синтетический спектр.

Выбраны строки 300–400 нм включительно и сохранена каждая вторая строка, чтобы уложиться в поддерживаемый размер набора без интерполяции, усреднения или изменения интенсивностей. Полное происхождение, условия, лицензия CC BY 4.0 и контрольные суммы находятся в `source-manifest.json`.

Воспроизведение и проверка:

```bash
pnpm experimental:import
pnpm experimental:check /path/to/Fig_2_total.dat
```

Команда импорта скачивает ровно один зафиксированный файл, проверяет SHA-256 и не выполняет массовый скрейпинг. Приложение и production-сборка к Zenodo не обращаются.
