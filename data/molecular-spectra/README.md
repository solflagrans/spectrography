# Молекулярные спектральные данные N₂ и N₂⁺

Ограниченная TSV-выгрузка построена из построчных баз `N2CB.db` и `N2PlusBX.db` проекта Moose/MassiveOES. Выбраны только характерные участки систем N₂ C³Πᵤ→B³Πg и N₂⁺ B²Σᵤ⁺→X²Σg⁺, покрываемые текущими оптическими измерениями; переходы с `J > 100` исключены как зафиксированное ограничение первой версии. Положения линий и коэффициенты Эйнштейна не изменяются и не дополняются предположениями.

Исходная версия, публикации, лицензия и SHA-256 перечислены в `source-manifest.json`. Выгрузка воспроизводится командой:

```bash
pnpm molecular:source /path/to/Moose/src/Moose/data
pnpm molecular:build
```

ExoMol WCCRMT версии 20240705 также проверен: он пригоден для N₂ и включает C–B, но в каталоге ExoMol нет N₂⁺. Для первой совместной модели N₂/N₂⁺ выбраны базы Moose/MassiveOES, предназначенные непосредственно для моделирования оптической эмиссии плазмы. Приложение использует только локальный сгенерированный файл и не обращается к этим источникам во время работы.
