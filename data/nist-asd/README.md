# Исходные данные NIST ASD

Каталог `raw` содержит ограниченную официальную TSV-выгрузку NIST ASD 5.12 и соседний файл с точными параметрами запроса, датой получения и SHA-256 исходного файла. Выгрузка охватывает только элементы приложения, степени ионизации I–II и диапазон 200–1000 нм. Параметр `line_out=3` ограничивает результат строками с наблюдаемой длиной волны или относительной интенсивностью.

Исходный файл получают вручную через официальный интерфейс NIST ASD Lines и сохраняют без правок. Приложение и production-сборка не обращаются к NIST. После замены выгрузки необходимо обновить дату и контрольную сумму в файле параметров, затем согласованно изменить константы генератора и выполнить:

```bash
pnpm library:build
pnpm library:check
```

Генератор парсит TSV, сохраняет отсутствующие поля отсутствующими, выбирает наблюдаемую длину волны как предпочтительную, а при её отсутствии — Ritz, сортирует линии и формирует детерминированные идентификаторы и контрольную сумму результата.
