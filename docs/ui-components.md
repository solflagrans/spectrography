# Общие компоненты интерфейса

Визуальные основы находятся в `src/components/ui`, размеры и цвета — в `src/styles/tokens.css`. Предметные вычисления и временное состояние анализа эти компоненты не меняют.

## Инвентаризация и замены

- Видимые селекторы уже использовали Radix Select; их меню и кнопки остаются общими.
- Поля поиска и диапазона используют Input с собственным оформлением; системные кнопки очистки и числовые спиннеры скрыты.
- Числовые параметры используют NumberField: локальный черновик, применение по blur/Enter, отмена по Escape, собственные кнопки шага. Введенные вручную значения проверяются существующим предметным конвейером.
- Checkbox и Switch используют настоящие checkbox-input с собственным оформлением; сохраняются подписи, Space и фокус.
- RangeInput использует настоящий range-input с собственными дорожкой, заполнением и бегунком для Chromium/WebKit и Firefox. Ползунок сохраняет существующее отложенное применение.
- Системное окно выбора файла остается функцией ОС. Скрытый file-input вызывается оформленной кнопкой приложения; файл выбирается только пользователем.
- Раскрывающиеся блоки используют общую основу Disclosure, включая единый маркер и клавиатурный фокус. SettingsDisclosure сохраняет собственную логику ошибок параметров.
- CardHeader, FieldLabel, MetricList, StatusBadge и общий стиль таблицы задают повторяющуюся геометрию; предметные компоненты управляют колонками, содержимым и адаптивностью.
- DialogSurface и DialogHeader используются для характеристик участка, импорта, справочных записей, диапазона графика и мобильного инспектора. Radix отвечает за Escape, захват и восстановление фокуса. Меню, подсказки и окна ограничены доступным экраном.

## Шкала

Основной текст и поля — 13 px, вспомогательный текст — 12 px, заголовки карточек — 16 px, страниц — 24 px. Высота обычного элемента — 32 px, компактной кнопки — 28 px. Отступы — 4/8/12/16/24 px. Для сенсорного ввода размеры увеличиваются. В forced-colors чекбоксы и переключатели возвращают системное отображение для доступности.

Не добавлять отдельные варианты цвета и рамки полей на страницах. Модификаторы страниц отвечают за компоновку, ширину, колонки и переносы, а не за независимую визуальную систему.
