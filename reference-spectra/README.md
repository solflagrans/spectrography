# Внешние эталонные спектры

Папка не подключена к приложению. Для ручной проверки загружайте файлы из `app-ready` на странице «Данные». Все пять JSON-файлов уже прошли штатный импорт приложения; каждый содержит меньше 10 000 точек.

Это эталонные **измерения образцов с известным составом**, а не универсальные абсолютные шаблоны интенсивностей. Относительные интенсивности LIBS зависят от прибора, энергии лазера, атмосферы и подготовки образца. Их правильное применение здесь — проверять обнаружение ожидаемых элементов, ложные совпадения, отказ от чрезмерно уверенного вывода и устойчивость обработки реальных данных.

## Что внутри

| Файл для загрузки | Известный состав / ожидаемый сигнал | Результат текущей версии |
| --- | --- | --- |
| `nasa-pds-gbw07216a-calcium-rich.json` | CaO 35,02%, MgO 17,88% | Ca остаётся ведущим; Fe поддержан как слабый компонент, сомнительные Ar/O отклонены |
| `nasa-pds-h92649-iron-rich.json` | Fe₂O₃* 95,84%, TiO₂ 2,09% | принят только Fe; прежняя ложная ведущая гипотеза Si отклонена |
| `nasa-pds-dh4911-magnesium-rich.json` | MgO 47,37%, SiO₂ 42,63%, Fe₂O₃* 7,89%; CaO лишь 0,49% | приняты Mg, Fe и сильный следовой Ca; сомнительный Hg отклонён |
| `nasa-pds-muscoc17-aluminium-rich.json` | SiO₂ 45,53%, Al₂O₃ 36,90% | Al и Si приняты; прежняя ложная гипотеза He отклонена |
| `zenodo-14843545-air-plasma-300-400nm.json` | воздушная плазма, характерные полосы N₂ | N₂ найден по четырём областям, атомные гипотезы не приняты — хороший молекулярный пример |

Во всех пяти случаях общая оценка пригодности остаётся `limited`: отдельные диапазоны не содержат явной заявленной неопределённости калибровки, поэтому приложение сохраняет осторожное предупреждение. Оно больше не превращает отклонённую альтернативу в принятую гипотезу.

`expectations.json` использует трёхзначную разметку: перечисленные элементы считаются `present`, а все неперечисленные — `unknown`, но не автоматически `absent`. Поэтому отчёт отдельно показывает ожидаемые, пропущенные и неразмеченные принятые элементы и не выдаёт неполную таблицу состава за доказательство отсутствия.

Полный машинный отчёт находится в `verification-report.json`. Исходные файлы без изменения лежат в `originals`, а `manifest.json` фиксирует URL, DOI, состав, преобразования и SHA-256.

## Происхождение

Четыре LIBS-спектра взяты из NASA PDS: M. Darby Dyar, Kate Lepore, *Multi-Parameter LIBS Reference Database of Geological Materials*, 2026, DOI `10.17189/b2aj-cz96`. Исходные ChemLIBS-спектры уже прошли вычитание тёмного сигнала, коррекцию отклика прибора и выравнивание шкалы по титановому стандарту; удаление базовой линии поставщик не выполнял. Для JSON усреднены пять несатурированных колонок `i1–i5`, длины волн не интерполировались.

Спектр воздушной плазмы взят из Zenodo record `14843545`, DOI `10.5281/zenodo.14843545`, лицензия CC BY 4.0. Для ограничения приложения оставлен диапазон 300–400 нм и каждая вторая исходная строка; значения интенсивности не менялись.

## Воспроизведение

Из корня репозитория:

```bash
node reference-spectra/tools/build-app-ready.mjs
pnpm exec tsx reference-spectra/tools/verify-with-app.ts --write
```

Первая команда повторно строит JSON из локально сохранённых оригиналов. Вторая прогоняет штатный импорт и текущий аналитический конвейер и обновляет локальный `verification-report.json`; в приложение и пользовательскую сессию она ничего не записывает.
