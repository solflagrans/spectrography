Multi-Parameter LIBS Reference Database of Geological Materials Bundle
M. Darby Dyar
Kate Lepore

This bundle contains the following collections:

data_chemlibs
- The data_chemlibs collection contains spectral data from the ChemLIBS instrument. The data are organized by 
atmosphere (earth, mars, vacuum) followed by laser energy (in mJ).

data_superlibs
- The data_superlibs collection contains spectral data from the SuperLIBS instrument. The data are organized by
resolution (10K or 18K) followed by atmosphere (earth, mars, vacuum) and laser energy (in mJ).

data_plibs_z300
- The data_plibs_z300 collection contains spectral data from the pLIBS Z-300 instrument.

data_plibs_z903
- The data_plibs_z903 collection contains spectral data from the pLIBS Z-903 instrument. 

document 
- The document collection contains a user's guide, a LIBS metadata document, and release notes.

Each document and data product in this bundle is described by a PDS4 label in a separate file with the same name 
but with the extension XML. PDS4 labels are XML (eXtended Markup Language) files that conform to the PDS4 Information 
Model XML schema at https://pds.nasa.gov/pds4/schema/released/. They are best viewed in an XML-aware text editor, and 
may be used by software that can manipulate XML documents.

See these sources for more information.

- For information about this bundle, see the document collection in this bundle. 
- For information about PDS4, see https://pds.nasa.gov/pds4/about/.
